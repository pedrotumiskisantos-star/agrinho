# agrinho
# 🌾 Agro Forte — Futuro Sustentável

Projeto de página institucional com foco no agronegócio sustentável, destacando o equilíbrio entre produção agrícola, tecnologia e preservação ambiental.

A proposta do site é apresentar informações modernas, organizadas e profissionais sobre o cenário do agro em 2026.

---

# 📸 Preview

Landing page moderna com:

- Hero section impactante
- Indicadores do agronegócio
- Sustentabilidade no campo
- Tecnologias agrícolas
- Design responsivo
- Visual profissional e moderno

---

- Flexbox
